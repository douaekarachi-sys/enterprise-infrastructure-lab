# Screenshots

Place the project screenshots in this folder. Suggested files:

- `topology.png` — PNETLab network topology (VLANs, switches, pfSense, servers)
- `active-directory.png` — Active Directory Users and Computers (OU structure)
- `zimbra-admin.png` — Zimbra administration console
- `dhcp-scopes.png` — DHCP scopes configuration
- `dhcp-script-output.png` — PowerShell DHCP script execution
- `pfsense.png` — pfSense firewall configuration

> ⚠️ Before uploading: make sure no screenshot contains real passwords,
> private IP/credentials, or sensitive information. Blur or crop anything
> sensitive (e.g. the admin password visible in console output).
